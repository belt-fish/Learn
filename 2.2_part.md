# 2.2 CMake 基础

## 环境

|       | 版本                                   |
| ----- | -------------------------------------- |
| cmake | 3.22.1                                 |
| 用途  | 普通 C++ 工程、ROS 2 的 ament_cmake 包 |

## 最小模板（普通工程）

```cmake
cmake_minimum_required(VERSION 3.16)
project(demo)
set(CMAKE_CXX_STANDARD 17)

add_executable(demo main.cpp)
```

编译运行：

```bash
cmake -B build -S .
cmake --build build -j
./build/demo
```

## 加一个库

```cmake
add_library(mylib SHARED src/mylib.cpp)
target_include_directories(mylib PUBLIC include)

add_executable(demo main.cpp)
target_link_libraries(demo PRIVATE mylib)
```

`PUBLIC` 表示"我自己用，链接我的人也能用"；`PRIVATE` 表示只自己用。

## ROS 2 包模板（可执行节点）

```cmake
cmake_minimum_required(VERSION 3.8)
project(my_node)

find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(std_msgs REQUIRED)

add_executable(my_node src/main.cpp)
ament_target_dependencies(my_node rclcpp std_msgs)

install(TARGETS my_node DESTINATION lib/${PROJECT_NAME})
ament_package()
```

## ROS 2 包模板（只有资源）

```cmake
cmake_minimum_required(VERSION 3.8)
project(my_bringup)

find_package(ament_cmake REQUIRED)

install(DIRECTORY launch config rviz
  DESTINATION share/${PROJECT_NAME})

ament_package()
```

## 常用命令

| 命令                             | 作用          |
| -------------------------------- | ------------- |
| `find_package(包 REQUIRED)`      | 找依赖        |
| `add_executable` / `add_library` | 定义目标      |
| `target_include_directories`     | 头文件目录    |
| `target_link_libraries`          | 链接库        |
| `target_compile_options`         | 编译选项      |
| `install(TARGETS ...)`           | 安装可执行/库 |
| `install(DIRECTORY ...)`         | 安装资源目录  |

## ROS 2 的编译

```bash
colcon build --packages-select 包名
source install/setup.bash
```

## 踩坑

改完 CMakeLists 必须重新 `colcon build`。
`install/` 里放的是**副本**，不重编的话运行起来用的还是旧文件，
表现为"明明改了却没生效"，很容易怀疑到代码上。
