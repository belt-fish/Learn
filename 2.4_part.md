# 2.4 ROS 2 基础

## 环境

|          | 值                   |
| -------- | -------------------- |
| 发行版   | ROS 2 Humble         |
| 安装路径 | `/opt/ros/humble`    |
| 中间件   | DDS（默认 Fast DDS） |

## 五个核心概念

| 概念           | 一句话                  | 例子                           |
| -------------- | ----------------------- | ------------------------------ |
| 节点 Node      | 一个功能单元            | `/slam_toolbox`、`/diff_drive` |
| 话题 Topic     | 持续的数据流，发布/订阅 | `/scan`、`/odom`、`/cmd_vel`   |
| 服务 Service   | 一问一答，立即返回      | `/spawn_entity`                |
| 动作 Action    | 长任务，有反馈、可取消  | `/navigate_to_pose`            |
| 参数 Parameter | 节点的配置项            | `use_sim_time`                 |

## 什么时候用哪个

- 连续数据（传感器、速度指令）→ 话题
- 立刻要结果（存图、生成模型）→ 服务
- 要几秒钟以上、要进度（导航）→ 动作

## 工作空间

```
ws/
├── src/          你写的包
├── build/        编译中间产物（生成）
├── install/      安装结果（生成，source 这个）
└── log/          编译日志（生成）
```

```bash
colcon build --packages-select 包名
source install/setup.bash
```

## 常用命令

```bash
# 包与节点
ros2 pkg list
ros2 pkg prefix 包名
ros2 run 包名 可执行名
ros2 launch 包名 xxx.launch.py
ros2 node list
ros2 node info /节点名

# 话题
ros2 topic list -t
ros2 topic echo /scan --once
ros2 topic hz /scan
ros2 topic info /cmd_vel -v
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{}"

# 服务 / 动作 / 参数
ros2 service list -t
ros2 service call /xxx 类型 "{...}"
ros2 action list
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose "{...}"
ros2 param list /节点
ros2 param get /节点 参数名
ros2 param set /节点 参数名 值

# 其他
ros2 interface show geometry_msgs/msg/Twist
ros2 bag record -a
ros2 bag play 包名
ros2 doctor
```

## QoS（容易踩）

| 策略        | 常用值                     | 含义                                |
| ----------- | -------------------------- | ----------------------------------- |
| Reliability | RELIABLE / BEST_EFFORT     | 保证送达 / 尽力而为                 |
| Durability  | VOLATILE / TRANSIENT_LOCAL | 只给在线订阅者 / 后来者也能收到历史 |

**`/map` 必须是 TRANSIENT_LOCAL**，否则 RViz 后开会收不到地图，显示 `No map received`。

## launch 文件长什么样

```python
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(package='my_pkg', executable='my_node', output='screen'),
    ])
```

```bash
ros2 launch my_pkg xxx.launch.py rviz:=true
```

## 踩坑

每开一个新终端都要重新 `source install/setup.bash`。
不 source 就报 `Package not found`，而且报错完全不会提示你是没 source。
