## 安装

```bash
# 深度学习框架
pip3 install --user torch torchvision

# YOLO 训练框架
pip3 install --user ultralytics

# 模型导出与推理
pip3 install --user onnx onnxruntime
```

装不上的话换镜像源：

```bash
pip3 install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名
```

## 验证

```bash
python3 -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python3 -c "import ultralytics; print(ultralytics.__version__)"
python3 -c "import cv2; print(cv2.__version__)"
nvidia-smi
```

`torch.cuda.is_available()` 要输出 `True` 才算能用 GPU。

## 问题

| 现象                           | 原因                | 处理                   |
| ------------------------------ | ------------------- | ---------------------- |
| `cuda.is_available()` 为 False | 装成了 CPU 版 torch | 卸了重装对应 CUDA 版本 |
| `nvidia-smi` 报错              | 驱动没装好          | 先去装显卡驱动         |
| 装包很慢 / 超时                | 默认源慢            | 换清华或阿里源         |
| 版本冲突                       | 多个包互相依赖      | 用虚拟环境隔离         |

## 虚拟环境

```bash
python3 -m venv .venv
source .venv/bin/activate
pip3 install ...
deactivate
```

每个项目一个环境，避免互相污染。

## 踩坑

1. 机器上没装 `nvcc` 也能用 GPU，PyTorch 自带 CUDA 运行时，不用单独装 CUDA Toolkit。
