# 常见问题

跑这套导航时踩过的坑，按类别整理。每条写清楚：**看到什么现象 → 为什么 → 怎么处理**。

## 一、启动

| 现象 | 原因 | 处理 |
|---|---|---|
| `Package not found` | 新终端没加载工作空间 | `source install/setup.bash`，每个终端都要 |
| 起了 Nav2 但 RViz 一片空白，没有地图 | 节点还没 active，或者 Fixed Frame 不对 | 等 9 个节点 active；RViz 里 Global Options → Fixed Frame 选 `map` |
| `planner_server` 一直 inactive | 拿不到 `map→base_footprint`，AMCL 没定位 | 看 `ros2 topic echo /amcl_pose --once`；本项目配了 `set_initial_pose: true`，一般不用手点 |
| 点了目标点没反应 | Nav2 节点没起来 / 没订阅 `/goal_pose` / 目标点在墙里 | `ros2 node list` 看节点；`ros2 topic info /goal_pose` 看订阅者有没有 `bt_navigator` |
| 一启动就报 TF 相关的错 | 仿真还没起完就起了 Nav2 | 起完仿真等 20 秒，再起 Nav2 |
| 两个终端互相看不到话题 | `ROS_LOCALHOST_ONLY` 不一致 | 所有终端都 `export ROS_LOCALHOST_ONLY=1` |

## 二、导航

| 现象 | 原因 | 处理 |
|---|---|---|
| 车原地打转，或者一动就像散架 | 从动轮是 `type="fixed"` 关节，被合并进父 link，`<mu1>` 设置失效，变成刹车片 | 从动轮关节改成 `continuous` |
| 车打滑，指令走 0.8 m 实际只走 0.3 m | 世界文件的 `contact_max_correcting_vel` 太小（0.01 会废掉牵引力） | 改成 `10.0` |
| 起步反应很肉 | `max_wheel_acceleration` 太小 | 6.0 左右比较跟手 |
| 规划一直失败，找不到路 | `inflation_radius` 太大，把走廊吃光了 | 走廊 1 m 时别超过 0.5 |
| 到点了不停 | goal checker 容差太小 | 调 `xy_goal_tolerance` / `yaw_goal_tolerance` |
| 车贴着墙蹭 | 局部代价地图的膨胀不够 | 适当加大 `inflation_radius` |

## 三、建图

| 现象 | 原因 | 处理 |
|---|---|---|
| 墙是锯齿，还散着小黑点 | 雷达角度分辨率不够，点比地图格子稀 | `samples` 360 → 720 |
| 走快了地图就歪 | 速度 × 帧间隔 > 分辨率 / 2 | 0.03 m 格子 + 15 Hz，速度别超过 0.22 m/s |
| 松手之后车还在跑 | Gazebo 差速驱动会一直保持最后一条 `/cmd_vel` | 加速度看门狗，3 秒没指令补零 |
| 中途刹不住、转不了 | 开了两个 teleop，两边各发各的互相覆盖 | `ros2 topic info /cmd_vel -v` 确认只有一个发布者 |
| `TF_OLD_DATA` 刷屏 | 插件发的 TF 时间戳倒退 | 关掉插件的 `<publish_odom_tf>`，用 ROS 节点发，时间戳用 `/odom` 里的 |

## 四、其他

| 现象 | 原因 | 处理 |
|---|---|---|
| mp4 打不开 | 系统没装 H.264 解码器 | `sudo apt install gstreamer1.0-libav` |
| 电脑变卡、风扇狂转 | 残留的 gzserver / rviz2 有好几套 | `bash ~/清理所有残留.sh` |
| Windows 和 Ubuntu 时间差 8 小时 | 两边对硬件时钟的时区解释不一样 | `timedatectl set-local-rtc 1 --adjust-system-clock` |
| 改了代码没效果 | 没重新 `colcon build`，跑的还是 `install/` 里的旧版本 | 重编 + 重新 source |

## 五、排查用的命令

```bash
# 节点齐不齐
ros2 node list

# Nav2 节点状态
ros2 lifecycle get /planner_server

# 地图有没有发出来
ros2 topic echo /map --once --field info.resolution

# 目标点话题的收发双方
ros2 topic info /goal_pose -v

# TF 通不通
ros2 run tf2_ros tf2_echo map base_footprint

# 激光频率
ros2 topic hz /scan

# 谁在发速度指令
ros2 topic info /cmd_vel -v
```

## 六、清场

跑之前最好清一下残留，不然旧进程会抢话题：

```bash
bash ~/清理所有残留.sh
```

没这个脚本的话：

```bash
pkill -9 gzserver gzclient rviz2
```
