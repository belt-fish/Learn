## 一个完整的最小程序

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    int a = 1;
    double b = 3.14;
    std::string s = "hello";
    std::vector<int> v = {1, 2, 3};

    if (a > 0) {
        std::cout << "a is positive" << std::endl;
    }

    for (int i = 0; i < 3; i++) {
        std::cout << v[i] << " ";
    }

    for (const auto &x : v) {          // 范围 for，加 & 避免拷贝
        std::cout << x << " ";
    }

    std::cout << s << b << std::endl;
    return 0;
}
```

## 函数

```cpp
int add(int a, int b = 0);              // 默认参数只能写在声明里
void modify(std::vector<int> &v);       // 引用传参，能改调用者的变量
void print(const std::vector<int> &v);  // const 引用，只读不拷贝
```

**大对象一律用 `const T&` 传**，避免整份拷贝（比如 ROS 的 Path、Image）。

## 类的三种写法

```cpp
class Foo {
public:
    Foo() = default;                  // 默认构造
    Foo(int x) : x_(x) {}             // 初始化列表

    void run() const { /* 不改成员 */ }

private:
    int x_ = 0;                       // 就地初始化，推荐
};

class Bar : public Foo {              // 继承
public:
    void run() override { }           // 重写，一定要写 override
};
```

- `override` 写错签名时编译器会报错，不写就悄悄变成一个普通函数
- 基类的析构函数要写成 `virtual`

## 指针 vs 引用

|              | 引用 `T&`    | 指针 `T*`       |
| ------------ | ------------ | --------------- |
| 能不能为空   | 不能         | 能（`nullptr`） |
| 能不能改指向 | 不能         | 能              |
| 传参时的意思 | 一定会传进来 | 可能传空        |

## 智能指针

```cpp
auto p = std::make_shared<Foo>(1);   // 共享所有权
auto q = std::make_unique<Foo>(1);   // 独占所有权
```

不用手写 `delete`，离开作用域自动释放。

## 常见编译错误

| 报错                                    | 原因                       |
| --------------------------------------- | -------------------------- |
| `was not declared in this scope`        | 没 include 或名字写错      |
| `undefined reference to`                | 声明了没实现，或库没链接上 |
| `no matching function for call`         | 参数类型或个数不对         |
| `marked override but does not override` | 签名和基类不一致           |

## 踩坑

编译不加 `-std=c++17` 时，`auto`、结构化绑定这些会报错；
忘了 `#include <iostream>` 就用 `std::cout`，报错信息会指向一堆看不懂的模板内部。
