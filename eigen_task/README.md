# Eigen 本节任务：坐标系变换

## 题目要求

已知目标在相机坐标系下的位姿 `p_co`、`R_co = Rz(60°)`，
相机到世界的外参 `p_wc`、`R_wc = Ry(90°)`，
求目标在世界坐标系下的 `p_wo` 和 `R_wo`。

## 实现了什么 / 用了什么写法

| 实现了什么 | 用了什么写法 |
|---|---|
| 构造绕 Y 轴、Z 轴的旋转矩阵 | 自己写 `rotY()` / `rotZ()`，角度转弧度后填 3×3 矩阵 |
| 定义向量和矩阵 | `Eigen::Vector3d`、`Eigen::Matrix3d`，固定尺寸，维度写错编译期就报 |
| 求旋转 | `R_wo = R_wc * R_co`，两个矩阵相乘 |
| 求位置 | `p_wo = R_wc * p_co + p_wc`，矩阵乘向量再加平移 |
| 去掉浮点误差 | `unaryExpr` 把 1e-17 这种值抹成 0 |
| 输出对齐 | `std::fixed` + `setprecision(4)` |
| 自检 | 和手算的 `[5.5, -0.6, 0.8]` 比，误差小于 1e-9 打印"结果正确" |

## 怎么运行

```bash
cd eigen_task
cmake -B build -S .
cmake --build build -j
./build/eigen_task
```

## 输出

```
p_wo =  5.5000 -0.6000  0.8000 m
R_wo =
 0.0000  0.0000  1.0000
 0.8660  0.5000  0.0000
-0.5000  0.8660  0.0000
结果正确
```

## 踩坑

旋转矩阵是**左乘**：先转到相机系下的姿态 `R_co`，再由相机系转到世界系，
所以世界系下是 `R_wc * R_co`。写反了结果完全不同。

平移那一步是**先旋转再平移**：`R_wc * p_co + p_wc`，
不是 `R_wc * (p_co + p_wc)`。
